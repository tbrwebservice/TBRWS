Política de privacidad

Última actualización: 20 de octubre de 2026.

Esta política explica cómo TBR Web Service trata los datos que una persona comparte al realizar una consulta desde este sitio.

Datos que podemos recibir

El formulario solicita nombre, email, empresa de manera opcional y el mensaje sobre el proyecto. No envíes información sensible, como datos de salud, documentos de identidad, datos bancarios o contraseñas.

Para qué usamos los datos

Usamos estos datos únicamente para responder la consulta, preparar una propuesta si corresponde y mantener el intercambio relacionado con el proyecto solicitado.

Cómo se envía la consulta

El formulario se procesa mediante FormSubmit para entregar el mensaje a la casilla de contacto de TBR Web Service. Este proveedor recibe los datos necesarios para realizar ese envío. También usamos Google Fonts para mostrar las tipografías del sitio.

Conservación y derechos

El plazo de conservación de las consultas debe ser definido por TBR Web Service antes de realizar campañas o ampliar el uso de los datos. Podés solicitar acceso, rectificación, actualización o eliminación de tus datos escribiendo a tomasbenjaminramos2000@gmail.com.

Cookies y analítica

En su configuración actual, el sitio no activa analítica ni cookies de marketing. Si se habilita analítica en el futuro, esta política se actualizará antes de activar cualquier tecnología que requiera consentimiento.

Nota: este texto informa el funcionamiento actual del sitio y no reemplaza asesoramiento legal. TBR Web Service debe revisar y definir su política de conservación de datos antes de una campaña de captación.
